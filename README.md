# Snapshot — screenshot & annotate (Windows / macOS)

Кросплатформений застосунок на Electron: скрін екрана → виділення області → малювання → зберегти у файл або скопіювати в буфер.

## Можливості
- **Гаряча клавіша** `Ctrl/Cmd + Shift + X` (змінюється в налаштуваннях) — робить скрін і відкриває оверлей поверх усіх вікон (працює і з іконки в треї).
- **Меню в треї:** «Start at login» (автозапуск) і «Change shortcut…» (зміна комбінації через окреме вікно налаштувань). Налаштування зберігаються у `config.json` в userData.
- **Виділення області** мишкою; поза виділенням екран затемнюється, показується розмір у пікселях.
- **Інструмент «Курсор» (move):** перетягування всієї виділеної області та **масштабування** її за 8 маркерів по кутах/сторонах.
- **Інструменти малювання:** олівець, стрілка, лінія, прямокутник, еліпс, текст.
- **Колір** (8 кольорів) і **товщина** (3 варіанти).
- **Undo** (`Ctrl/Cmd + Z`), скасувати — `Esc`.
- **Save** — діалог збереження PNG (за замовч. у Pictures). **Copy** (`Ctrl/Cmd + C`) — виділена область у буфер обміну.
- Оверлей — **справжній повний екран** (перекриває панель задач / док / меню-бар).
- Мультимонітор: оверлей створюється на кожному екрані.

### Гарячі клавіші в оверлеї
`V` курсор (рух/масштаб області) · `P` олівець · `A` стрілка · `L` лінія · `R` прямокутник · `O` еліпс · `T` текст · `Ctrl/Cmd+Z` undo · `Ctrl/Cmd+C` копіювати · `Ctrl/Cmd+S` зберегти · `Esc` вихід.

## Запуск (dev)
```bash
cd screenshot-app
npm install
npm start
```
Вікна одразу не буде — застосунок живе в треї. Натисни `Ctrl/Cmd+Shift+X` або клікни іконку в треї, щоб зробити скрін.

## Збірка інсталяторів
```bash
npm run dist:win   # Windows: NSIS-інсталятор + portable .exe (у dist/)
npm run dist:mac   # macOS: .dmg (запускати на Mac)
```
> macOS збирається тільки на macOS. Windows-таргет — на Windows.

## Автозбірка в хмарі (GitHub Actions)
У репозиторії є `.github/workflows/build.yml`. Він збирає **обидві** платформи без потреби мати Mac під рукою:

- **Пуш тегу** `vX.Y.Z` → збирає Windows `.exe` + Mac `.dmg` (arm64 + Intel) і викладає їх у **GitHub Release**.
- **Ручний запуск** (Actions → Build installers → Run workflow) → збирає й кладе інсталятори як artifacts (без релізу).

```bash
git tag v1.0.0
git push origin v1.0.0
```

Через кілька хвилин файли з'являться у розділі **Releases** репозиторію.

## macOS: встановлення завантаженої збірки
Збірка **не підписана** сертифікатом Apple Developer (безкоштовний варіант), тому після завантаження з інтернету macOS блокує її: «Програму "Snapshot" пошкоджено» / «не вдається перевірити розробника». Файл цілий — треба лише зняти «карантин»:

1. Відкрийте `.dmg` і перетягніть **Snapshot** у папку **Програми** (Applications). Запускати треба саме звідти, не з образу `.dmg`.
2. Зніміть карантин однією командою в Terminal:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Snapshot.app
   ```
   *Альтернатива без терміналу:* спробуйте відкрити → **Системні параметри → Конфіденційність і безпека** → внизу **«Все одно відкрити»**.
3. Далі відкривайте подвійним кліком.

> На Apple Silicon застосунок ad-hoc підписаний під час збірки (`build/afterPack.js`), тож після зняття карантину відкривається без «damaged». Повністю без цього кроку — лише з платним Apple Developer ID + нотаризацією.

## macOS: дозвіл на запис екрана
Перший запуск попросить дозвіл: **System Settings → Privacy & Security → Screen Recording** → увімкнути Snapshot, потім **перезапустити застосунок**. Якщо перемикач стоїть, але захоплення не працює (буває після оновлення непідписаної збірки) — приберіть Snapshot зі списку кнопкою «–» і додайте наново, або виконайте `tccutil reset ScreenCapture com.malse.snapshot`.
